## 运行架构

### 配置与水体控制

- `WaterSurfaceData`：波浪、随机种子、吸收渐变、散射渐变和泡沫曲线。
- `WaterSettingsData`：反射模式及平面反射设置。
- `WaterResources`：默认水面材质、水纹、泡沫和泡沫 Ramp 纹理引用。
- `Water.cs`：读取这些配置，生成波浪和颜色查找表，上传 Shader 全局参数，管理平面反射组件，捕获地形高度并释放临时资源。


波浪参数可以通过 Vector 数组或 ComputeBuffer 上传。`computeOverride=true` 使用数组；关闭后在设备支持时使用 ComputeBuffer。两条路径均限制最多 10 个波浪。当前设计使用全局 Shader 参数，不是每片水面独立管理全部状态的系统。

### 水面着色

`Water.shader` 定义材质属性、Pass 和关键字，调用 `WaterCommon.hlsl` 中的顶点与片元入口。

- 顶点阶段：读取地形高度图取得浅水信息，计算 Gerstner 位移与法线，输出世界坐标、屏幕坐标、雾及辅助数据。
- 片元阶段：读取相机深度和不透明颜色，计算水深、细节法线、折射、菲涅耳、反射、光照、散射及泡沫，最后合成并混雾。
- `GerstnerWaves.hlsl`：单波计算、多波叠加和浅水衰减。
- `WaterLighting.hlsl`：菲涅耳、水中阴影采样和反射采样。
- `WaterInput.hlsl`：水面参数、纹理及采样器声明。
- `CommonUtilities.hlsl`：水面使用的噪声辅助函数。

材质保留静态模式及散射、折射、反射、法线、菲涅耳、泡沫、水深调试视图。

### 三条辅助渲染流程

1. **地形高度捕获**：`Water.cs` 设置俯视正交相机 → 专用 Renderer 的 `WaterTerrainDepthFeature` 显式绘制选定层的 MeshRenderer → `SurfaceDepth.shader` 将高度编码进 RFloat 纹理 → 水面读取 `_WaterDepthMap`。这与片元阶段读取的相机深度不是同一张图；该捕获流程目前不直接绘制 Unity Terrain。
2. **平面反射**：`PlanarReflections.cs` 创建镜像相机，设置反射矩阵、裁剪平面和反射纹理，通过 `SubmitRenderRequest` 渲染 → 水面采样 `_PlanarReflectionTexture`。当前使用此模式，同时保留 Cubemap 和 ReflectionProbe 模式。
3. **水底焦散**：主 Renderer 的 `WaterCausticsFeature` 添加 RenderGraph 全屏 Pass → `Caustics.shader` 从相机深度重建世界位置，进行光照方向投影、纹理动画、深度遮罩和混合 → 将焦散叠加到场景颜色。

### 编辑器工具

- `SurfaceDataEditor.cs`：配置变化后通知关联水面刷新。
- `WaterSceneTools.cs`：打开现有场景、检查并输出整体与调试截图。
- `ObjectsImportValidation.cs`：检查场景素材的材质、网格、缺失脚本和地形数据。

验证输出位于 `Logs/Water`。工具不负责重建场景。
